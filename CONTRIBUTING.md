# Contributing

Contributions must distinguish verified observations from hypotheses and include enough information for independent reproduction.

Every hardware experiment should record:

- console model and southbridge family
- system-software version
- exact source revision and build command
- input and output paths
- whether every opened device was read-only or writable
- expected and observed sizes
- SHA-256 hashes of locally retained artifacts
- observed failure mode and recovery outcome

Do not submit copyrighted Sony binaries, console-unique secrets, credentials, or personal data.
